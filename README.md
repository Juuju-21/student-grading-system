# Student Grading System

A simple student grading system built with HTML, CSS and JavaScript.

Features

- Enter a student's name
- Enter the student's mark
- Calculate the student's grade
- Display the result
  Grade Scale

- A: 80 - 100
- B: 70 - 79
- C: 60 - 69
- D: 50 - 59
- E: 40 - 49
- F: Below 40

 Technologies Used

- HTML
- CSS
- JavaScript

 What I Learned

This project helped me practice JavaScript functions, user input, conditional statements and displaying results on a webpage.
